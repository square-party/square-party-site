# Source Documents — index and placement

A reference for orienting a new conversation: where Paul's uploaded source
documents currently sit on the site, what's been done with them, and what
remains.

This document is internal — not public-facing — and is kept current as
source documents are added or relocated.

Last regenerated: 2026-04-29.

---

## Conventions

- **Source doc** — a markdown or HTML file Paul has uploaded to a working
  conversation. Source docs are working drafts; they are not themselves
  published on the site, but their content gets condensed, voice-swept, and
  placed.
- **On-site location** — the site URL where the source content (or a
  derivative of it) currently lives.
- **Status** — *placed* (content is on the site), *partial* (some content
  used but more available), *not-yet-placed* (uploaded but no on-site
  derivative), *superseded* (content is on the site but the source has been
  revised since).
- **Recommended next step** — what would advance this source doc's
  treatment if next session targets it.

## How to use this document in a new conversation

1. Open with: "I'm continuing work on the Square Party site. Here's the
   source-doc index" — paste relevant rows or attach the file.
2. Tell Claude which source doc(s) and which on-site location(s) the
   conversation will focus on.
3. Reference companion docs: `SITE_REFERENCE.md` for the site's current
   structure, `VOICE_GUIDE.md` for editorial voice.

The index gets updated as source docs are added, placed, or revised.
Status changes (e.g., `partial` → `placed` after a deeper pass) should be
captured here so future sessions don't redo work.
